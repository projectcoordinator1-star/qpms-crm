# PROJECT CONTEXT

## Project Name
QPMS CRM

## Project Type

# Business Overview

QPMS CRM is being developed as a centralized enterprise workflow platform for Facilities Management operations.

The system is designed to manage:
- Lead collection
- Site assessments
- Commercial approvals
- HR validation
- Finance approvals
- Proposal generation
- MOM generation
- Operational workflows

The platform will eventually evolve into:
- CRM
- CAFM
- Operations Management System
- Approval Management Platform
- Analytics Dashboard
- Mobile Workforce Platform
